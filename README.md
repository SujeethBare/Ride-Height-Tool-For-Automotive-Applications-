# Ride Height Tool For Automotive Applications 
Ride Height Tool For Automotive Applications Ride height tool for a pickup truck. Pick a load case (curb, design, max, fuel, trailer) and it calculates axle loads, spring deflection, pitch, ground clearance and ride heights at tracked body points. 

A simple tool that predicts how a vehicle sits on the ground under different loads. It uses a free body diagram (sum of forces and moments) to split the load between the axles. Hooke’s law then turns the axle loads into spring deflections. From those it reports pitch, ground clearance change and the new height of points like the headlamp, rocker and trailer hitch.
